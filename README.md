# Breast Cancer Classification Using Neural Networks

## 📌 Project Overview
This project implements a Breast Cancer Classification model using a Neural Network (NN) to predict whether a tumor is **Malignant (Cancerous)** or **Benign (Non-Cancerous)**. The model is built using Python and TensorFlow/Keras and was developed in Google Colab.

## 🎯 Objectives
- Classify breast cancer tumors as malignant or benign.
- Apply data preprocessing and feature scaling techniques.
- Build and train a Neural Network model.
- Evaluate model performance using accuracy metrics.

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

## 📂 Dataset
The project uses the **Breast Cancer Wisconsin Diagnostic Dataset** available through Scikit-learn.

### Target Classes
| Label | Class |
|---------|---------|
| 0 | Malignant |
| 1 | Benign |

## 🔄 Project Workflow
1. Load the dataset.
2. Perform data preprocessing.
3. Split data into training and testing sets.
4. Normalize feature values.
5. Build the Neural Network model.
6. Train the model.
7. Evaluate model performance.
8. Make predictions on new data.

## 🧠 Model Architecture
- Input Layer
- Dense Hidden Layer (ReLU Activation)
- Dense Hidden Layer (ReLU Activation)
- Output Layer (Sigmoid Activation)

## 📊 Results
The trained Neural Network achieves high classification accuracy on the test dataset, demonstrating the effectiveness of Deep Learning techniques for medical diagnosis.
